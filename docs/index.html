04

The 7 Failure Modes

Key insight: agent psychology = human psychology. Same fixes that make humans productive work on agents.

Pre-Task

1. Incomplete Context
Sign: coding without reading files
Fix: read ALL related files first
2. Misalignment
Sign: quick fix instead of right fix
Fix: think founder, not contractor

During Task

3. Context Anxiety
Sign: quality drops late in session
Fix: /compact or hand off summary
4. Planning Deviations
Sign: A' instead of A
Fix: verify against plan each step
5. Complexity Fear
Sign: stubs, "out of scope"
Fix: decompose to sub-100-line tasks

Post-Task

6. Verification Laziness
Sign: "should work", no evidence
Fix: run checks, show output
7. Entropy Maximization
Sign: stale docs after changes
Fix: update ALL references

Token Efficiency

Cost = S x N(N+1) / 2
Message 30 costs 31x message 1. Context reloads every turn.
Situation Action Savings
Claude misunderstood Edit original, don't follow up No history stack
Chat > 15-20 messages Summarize -> new chat -> paste Reset quadratic
Multiple questions Batch into one prompt 2x+ fewer loads
Simple task Use Haiku model 50-70% cheaper
Going AFK > 5 min Run /compact first Avoid 10x spike
Tool schemas bloating ENABLE_TOOL_SEARCH=true -20K tokens/turn
Verbose responses Terse output (45 vs 180 tokens) 75% per turn
