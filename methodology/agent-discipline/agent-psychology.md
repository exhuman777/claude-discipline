# Agent Psychology = Human Psychology

The same productivity methods that work on humans work on agents.

## The Parallels

| Human Problem | Agent Problem | Same Solution |
|--------------|--------------|---------------|
| Procrastination on big tasks | Stubs and "out of scope" | Break into tiny steps |
| Rushing to finish before deadline | Quality drops as context fills | Set intermediate checkpoints |
| Skipping tests because "it looks right" | Weak verification | Make testing the easiest next step |
| Not updating docs | Stale references accumulate | Include cleanup in the task definition |
| Decision fatigue | Model degradation over long sessions | Fresh sessions, clear scope |

## The Insight

Reduce activation energy to near zero. Each subtask should be so small the agent can't rationalize avoiding it. "Write a 3-line test" has near-zero activation energy. "Implement the full authentication system" has massive activation energy.

## Application

This is why [[../planning/decompose-complexity]] works -- it's the GTD (Getting Things Done) principle applied to agents. And why [[harness-design]] includes complexity classification -- catching big tasks before the agent sees them.

500 small tasks > 1 massive task. For humans and agents alike.
