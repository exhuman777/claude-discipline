# compound-engineering

**What it solves:** No strategic planning. "Just start coding" approach creates tech debt.

**Install:**
```bash
/plugin marketplace add EveryInc/compound-engineering-plugin
/plugin install compound-engineering
```

**Workflow:** Brainstorm (20%) -> Plan (30%) -> Execute (20%) -> Review (20%) -> Extract (10%). 80% planning and review, 20% execution.

**Key commands:** `/ce:brainstorm`, `/ce:plan`, `/ce:work`, `/ce:review`, `/ce:compound`, `/ce:ideate`

**How it complements discipline:** Discipline provides rules. Compound-engineering provides strategic workflow. Use discipline for token efficiency and failure mode prevention. Use compound-engineering for larger architectural decisions.

**Overlap with superpowers:** Both have brainstorming and planning. Superpowers is better for debugging and TDD. Compound-engineering is better for strategic planning and pattern extraction.

**Token impact:** ~200-500 tokens per command.
