# arscontexta

**What it solves:** Building deep, structured knowledge bases. Single skill files can't hold domain expertise -- skill graphs can.

**Install:**
```bash
/plugin marketplace add agenticnotetaking/arscontexta
/plugin install arscontexta@agenticnotetaking
```
Restart, then: `/arscontexta:setup` (20-minute conversational onboarding)

**What it generates:** A three-space knowledge vault (self/ + notes/ + ops/) with wiki-linked markdown files, MOCs, and a 6-phase processing pipeline (Record, Reduce, Reflect, Reweave, Verify, Rethink).

**How it complements discipline:** claude-discipline IS a skill graph -- it uses the same architecture arscontexta teaches. If you want to build skill graphs for other domains (trading, legal, company knowledge), arscontexta is the tool.

**Backed by:** 249 interconnected research claims covering cognitive science, zettelkasten, graph theory, and agent architecture.

**Prerequisites:** Claude Code v1.0.33+, `tree`, `ripgrep`. Optional: `qmd` for semantic search.

**Source:** github.com/agenticnotetaking/arscontexta
