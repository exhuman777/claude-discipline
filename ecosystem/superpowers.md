# superpowers

**What it solves:** Claude codes before thinking. No TDD, no debugging methodology, no brainstorming phase.

**Install:**
```bash
/plugin marketplace add obra/superpowers
/plugin install superpowers
```

**Key skills:** brainstorming, systematic-debugging, test-driven-development, writing-plans, executing-plans, verification-before-completion

**How it complements discipline:** Discipline provides the rules (what to do). Superpowers provides the process (how to do it). Use discipline for efficiency and failure mode prevention. Use superpowers for structured workflows.

**Token impact:** ~200-500 tokens per invoked skill. Skills load on demand.
